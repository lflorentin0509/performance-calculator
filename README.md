# 📊 Performance Calculator

A responsive web application designed to calculate daily operational performance based on a process target and the user's System Net Productivity.

The project was created as a practical tool for logistics operations, allowing users to quickly understand how their daily performance compares against the expected target.

## ✨ Features

- Daily performance calculation
- Automatic target selection based on process
- System Net Productivity input
- Performance percentage calculation
- Target achievement visualization
- Animated performance gauge
- Progress bar against target
- Dynamic motivational messages
- Responsive mobile-first interface
- User name saved locally on the device
- Native result sharing on supported mobile devices
- Clipboard fallback for desktop browsers
- Support for decimal comma and decimal point
- Automatic current date
- No productivity data is stored
